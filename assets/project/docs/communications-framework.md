# 意图—设计—执行：主文与验证责任

默认主文三层，开头一条总判断；结论先行，随后给证据与解释，不在结尾再复制整篇判断。验证贯穿三层与QA，默认不单列章节。

- 意图：主推什么、争取谁、与谁竞争、希望改变什么选择。官方明确的竞争产品/模型版本要点名；官方主动对标、第三方评测、用户自行比较分别判断。目标反推不当内部方案。
- 设计：核心信息（KM）→证明材料/demo→目标受众与行动。能力主张配具体真实素材，标官方/第三方、读取深度与独立复测状态。数量与渠道功能分开展示。
- 执行：设计希望促成什么→实际发生什么→什么反馈支持或挑战目标。时序、接力、转折、争议与回应围绕主线组织；结果判断放在对应段落。

每段材料必须解释目的、关键设计或实际效果。重复判断、旁支案例与方法进折叠附录；关键效果图留主文。必须研究声量与持续性、信息传递、渠道数量/主体、节奏、路径、反馈行动；数据不够就给有依据的定性图或明确缺失，不造数凑图。

每图交代窗口、单位/分母、采集时点、来源和关键边界，链接逐条样本与计算。内容条数不是渠道全网份额，信息提及不是认同/触达，浏览相加不是独立人数，引用先后不是因果。

默认reading_mode=focused，资料附录折叠；重要未知就近限定结论。用户要求保留旧报告时隔离新稿；用户验收封版后记录哈希与版本，后续变化另立修订，不自动部署。
