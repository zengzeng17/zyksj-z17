# 研究与验收

确定对象、关键问题、版本和冻结窗；先查官方/原始触发帖，再查独立评测、用户任务、反例、转载和回应。不要把搜索摘要当原文。每条来源注明主体/源族、链接、读取深度、发布与采集时间、短摘录及可支撑的最窄事实。

取得计费授权后查当前余额和文档，单请求验证正文/列表字段，再有界分页。保留查询词、游标、页码、时间过滤、成本与停止原因；先排查语义、排序、参数及响应结构，再解释缺数。接口抓不到不等于没有讨论。

样本保留平台ID、URL、作者、发布时间/精度、采集时间、正文深度、纳排理由、引用/转载和互动出处。时间窗本地复核，区间记录单列。评论、内容条数、作者、浏览、触达与行动分别计数。

先时间线、再关键选择与效果；检验最强替代解释和反例。案例机制写适用条件、所需资源、代价及不适用情形，先作候选，不因一个成功例自动变通用规律。

validate不代替事实验证。审读原文、复算数字、检查反证和图表，查看桌面/手机；真实写入qa.json并绑定case哈希后build。更改保留旧发布及图表，不悄悄改历史。
