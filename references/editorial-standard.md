# 封版风格与审读清单

依据：用户于2026-10-28验收Kimi K3.1三层重构稿，并要求按此方向更新技能。继承的是组织与判断方式，不是该事件的竞争对象、因果解释或图表数量。

## 成稿形态

白底、单列、明确标题与段落层级，正文围绕一条主线。意图讲目的；设计给KM、素材、受众和渠道组合；执行把实际反馈与原意图对照。结果在对应段落说清，不再用独立“验证层”重复总结。研究深度留在来源、反证、样本和方法，不以主文长度体现。

模板默认 `reading_mode="focused"`：目录只保留总判断、三层分析和证据附录入口；详细时间线、方法、结论台账、机制、指标、缺口、来源折叠成附录。必要的关键节点与效果图仍需写入主文。

## 判断写法

- “旗舰比较” → 点名官方选择的模型/版本与任务；再解释希望进入谁的选型范围。
- “传播有成效” → 说明哪种能力获得谁的什么具体反馈；不把作品出现当成广泛认知成立。
- “承接没有跟上” → 写出实际卡点，例如任务未完成就触顶、推荐者开始解释自己是否收钱。
- “营销翻车” → 还原触发内容、放大主体、引用/转载关系与回应；截图归属未知与已观察到的信任质疑分别判断。

这是表达方式示例，不要求每个事件都存在上述现象。

## 发布前的阅读检查

1. 只读总判断与各层首段，能否知道目的、核心信息、实际结果/偏差？
2. “谁、什么产品、哪个版本、怎样的任务”是否能点名？是否把官方比较、第三方结论和我们的推断混在一起？
3. 每一段与图是否推进主线？同一结论是否被反复重述？删除某条旁支会不会改变判断？
4. 能力主张有没有具体demo或任务图像？来源、官方/第三方身份、读取深度和复测状态是否清楚？
5. 关键效果数据是否仍在主文？渠道是否有实取数量？小屏能否读懂，视频不能加载时是否仍有封面和原文入口？
6. 折叠附录是否保留证据、反证和口径？重要未知是否就近限定了相关结论，而非堆满每个段落？

不规定字数、图数或demo数量；以读者能清楚判断且证据够用为准。没有统一传播brief时，设计层必须说明是由公开动作反推。
